## 坐标与逐次变换

取 R 为纸面右、U 为纸面上、W 为纸外，R×U=W。向量均以 (R,U,W) 分量表示。⊙ 为 +W，⊗ 为 −W。B 的三列依次为 x、y、z；z 沿当前光线传播方向。反射后允许出现左手坐标像，不人为翻转一根轴来强行恢复右手系。

普通平面镜单位法向 n 的变换为：

`H(n) = I − 2nnᵀ`，`B_out = H(n) B_in`。

H 正交、行列式 −1。主截面普通反射的 n 在纸内，故 W 不变。已知入、出单位光向 k、k′ 时，可构造 `m = (k−k′)/|k−k′|`；这仅构造与给定折转相容的法向，不是从照片测得的实体法向。

标准屋脊主截面模型中，取两互相垂直的法向 `n₁=(m+W)/√2`、`n₂=(m−W)/√2`，则：

`Q = H(n₂)H(n₁) = I − 2mmᵀ − 2WWᵀ = H(m)H(W)`。

所以屋脊实际反射两次，等效纸内折转与 H(m) 相同，但纸外轴反号；det Q=+1。不是在一次普通反射上再加两次。两屋脊面谁先谁后无法由二维投影唯一命名；校验文件选择一种相容顺序，组合结果不受交换两面影响。

同一主截面的折射用保持手性的连续转动传递单位方向，W 不变。源码中的中间角度是定性光路的代表值，不是照片量角结果，也没有进行缺少折射率时无法进行的 Snell 定量追迹。

`tools/verify_optics.py` 对每一个真实反射分别施加 H，检查 BᵀB=I、z 的目标方向、`x×y=det(B)z`、累计反射奇偶性以及最终预期轴向。7 个模型、58 次变换、15 个检查点通过。逐次法向、矩阵、前后坐标保存于 `矩阵校验.json`。

### 实像与传播坐标的区别

物镜形成题干指定的实像，对**像的横向坐标方向**作 `B_P = B_前 diag(−1,−1,1)`：两个横向方向同时反号，传播 z 不反号，手性保持。这里表达像的方向，不能把这一变换说成又发生一次镜面反射；也不能仅因穿过透镜就给任意尚未成像的空间坐标加负号。实际放大率的绝对值不由本图给出。

与现有答案一致。改进了完整系统、反射编号、物镜与 P 的区分，并给出实像前后的坐标对照。

## 2025：必须保留的条件分支

### 已知与自选条件

原图没有给定入射坐标，不能把复绘中自选的坐标加到 source 图上。解图明确选：入射 x=−R、y=W、z=U。第一棱镜上部的成对线按屋脊，随后左下斜面普通反射；因此 a 处 x=U、y=−W、z=R，累计 3 次、左手系。

### 中间棱镜的不确定位置

请对照 `2025/prism2025-question.png` 的中间棱镜：上边及内侧长斜线近似成对，但外形具有透视；光线从下方折向左上，再向右下，在右下斜边处出现折向末端棱镜的拐点。重绘将该拐点标为 T*。

- **读法 A（交付主图的明确条件）**：中间上部成对线是屋脊标记；右下 T 是出射折射。中间只有一次普通反射和一组屋脊，实际 3 次。这个读法直接追踪可见光线离开轮廓的拓扑。
- **读法 B（现有参考解所需条件）**：中间内线是实体透视边，中间实际有 3 个普通反射面，且其有效传播属于同一主截面。现有文字没有说明第 3 个反射面具体对应哪块空间面；仅凭截图无法唯一确认。若第三次反射发生于 T 的投影位置，需要更清楚的三维面关系或教材棱镜标识支持，不能为了匹配答案凭空补面。

普通反射点通常使光继续留在同一介质一侧；在二维轮廓处直接离开的光线不能无条件当作内部镜面反射。透视可能隐藏面，故这里给出条件而不以像素角度裁决实体结构。

## 2026

### 复核与主解依据

第一棱镜顶部不像中间和末端那样存在清楚的两条完整平行斜边带；其淡线可能是顶边或实体透视边。因此主解将第一棱镜两个转折均按普通反射，**不额外补画一条屋脊线**。中间棱镜右下、末端棱镜右侧均有明确的成对斜线，按已确认约定处理为屋脊。

独立初读记录曾将第一棱镜顶部也算作屋脊。再次检查放大图后撤回这一无充分证据的主结论，保留为条件分支。修订依据是可见线条的完整性，不是强迫结果符合参考解。

## 复现

在仓库根目录运行：

```bash
python3 重绘交付/tools/verify_optics.py
python3 重绘交付/tools/draw_prisms.py --render
```

Python 脚本使用标准库；SVG 转 PNG 需要 Inkscape，中文字体使用 Noto Sans CJK SC。只生成 SVG 可省略 `--render`。PNG 输出透明，手机预览文件后缀为 `-350px.png`。渲染临时配置位于 `/tmp/prism-svg-render`，不修改用户主目录。矩阵 JSON 中 B 的列向量含义以本报告为准。

没有修改网站题库、题号、用户进度或原照，也没有上传网站。2025 年的未定面结构仍需外部证据，矩阵通过不代表该歧义已消除。
